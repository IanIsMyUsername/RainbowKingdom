# 词汇管理工具

这个工具用于方便地管理RainbowKingdom应用中的词汇数据。

## 文件说明

- `add_vocabulary.py` - 主要的词汇管理脚本

## 使用方法

### 1. 交互模式（推荐）

直接运行脚本，按照提示操作：

```bash
cd Tools
python add_vocabulary.py
```

### 2. 命令行模式

#### 快速添加词汇（推荐）
```bash
python add_vocabulary.py quick "hello" "你好"
```
只需要英文和中文，自动使用默认值：基础词汇 + 单词

#### 完整添加词汇
```bash
python add_vocabulary.py add "hello" "你好" "基础词汇" "单词"
```

#### 搜索词汇
```bash
python add_vocabulary.py search "hello"
```

#### 查看词汇列表
```bash
python add_vocabulary.py list 20
```

## 功能特性

- ✅ **简化模式**：只需输入英文和中文，自动使用默认值
- ✅ **完整模式**：可选择分类和类型
- ✅ **交互式添加**：友好的用户界面
- ✅ **批量添加**：支持批量操作
- ✅ **搜索功能**：查找现有词汇
- ✅ **查看列表**：显示最近添加的词汇
- ✅ **自动去重**：避免重复添加
- ✅ **自动日期**：自动添加当前日期
- ✅ **多种分类**：支持多种分类和类型

## 词汇分类

### 分类选项
- 基础词汇
- 常用短语
- 高级词汇
- 自定义分类

### 类型选项
- 单词
- 短语
- 自定义类型

## 数据格式

CSV文件格式：`英文,中文,分类,类型,添加日期`

示例：
```
hello,你好,基础词汇,单词,2025-01-15
Good morning,早上好,常用短语,短语,2025-01-15
```

## 注意事项

- 脚本会自动检查重复词汇，避免重复添加
- 添加日期默认为当前日期
- 支持中英文搜索
- 文件路径会自动处理，无需手动指定
